# Current document reference adapters

The internal deposit document binder requires an issuer port and a Masters template/layout port. The web adapters use the owners' genuine generated SDKs. Both retain the caller's original operation budget and the earliest inherited deadline, refuse ambient SQL transactions, validate the exact requested reference tuple, and charge elapsed owner time with a conservative millisecond quantum. No adapter or authenticated client is automatically activated.

The Masters adapter calls the emitted `DocumentReferenceCurrentControllerApi.observeCurrentDocumentReferences` operation. Its request binds tenant, product root, product ID, immutable revision, allocated publication, definition digest, enrollment purpose, document type/locale, and exact opaque template/layout references. The returned target must match. The retained layout definition must match the exact source revision/version/digest/locale and the `MASTERS_DOCUMENT_LAYOUT_V1` framed layout digest, including profile metadata and ordered notices. Layout metadata does not establish real assets or document rendering.

The Masters wire response contains `observedAtEpochMillis` and `effectiveUntilEpochMillis`. It provides no separate `nativeUntil` field. Internal observations therefore carry explicit `EFFECTIVE_ONLY` provenance and a null native deadline. A composed observation retains that provenance when either owner provides only an effective cap. The existing four-argument observation constructor preserves `NATIVE_AND_EFFECTIVE` behavior for existing callers such as the Config issuer adapter. Construction alone establishes no authority.

The supplied generated Masters client must have its declared bearer authentication configured. Missing clients or authentication, unavailable or mismatched owner bodies, noncanonical identities/locales, unsupported reference versions, expired original budgets, and invalid finite windows refuse without a successful fallback. The effective window cannot exceed five seconds and local narrowing does not extend any original owner, inherited, wall-clock, or monotonic boundary.

The web POM declares the Masters SDK dependency through `document-reference-sdk.version`. Source qualification uses the exact genuinely generated local JAR identified by the retained proof. That local artifact has the historical `26.10.6` coordinate; this does not show that the released artifact at that coordinate contains the new operation. A correctly allocated future release and real consumer adoption remain separate work. No cache installation or same-coordinate replacement is performed.

Tests use genuine generated serialization with controlled in-memory exchanges and a pure canonicalization vector checked against the actual compiled owner code. They do not establish current-owner HTTP/native acceptance, real provider/asset acceptance, or a financial journey. Deposit PUBLISH remains refused while the second native snapshot/CAS and owner-window admission, native expiry/forgery/deferred-commit qualification, and full integration remain open. The documented arbitrary-session `SET CONSTRAINTS` limitation remains unresolved.
